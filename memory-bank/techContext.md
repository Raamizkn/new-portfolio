# Tech Context: New Portfolio

## Technologies Used
- **Frontend:** Next.js 14/15, React, TypeScript
- **Styling:** Tailwind CSS, PostCSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Package Manager:** Yarn / NPM
- **Deployment:** Vercel (intended)

## Development Setup
- `yarn run dev`: Starts the development server at `localhost:3000`.
- `jsconfig.json` / `tsconfig.json`: Path aliases and TypeScript configuration.

## Technical Constraints
- Must be performant with image-heavy case studies.
- Needs to handle both light and dark modes gracefully.
- Responsive across all device sizes (mobile, tablet, desktop).
